# 新生 CableGenerator (V2) 要件定義・基本設計書

---

## 1. プロジェクト概要・コンセプト

### 1.1 コアビジョン
**「V1 の全機能を完全継承しつつ、Splines 依存を脱却し、説明書なしで直観・最少手数で使える軽量ツールへ進化させる」**

親フォルダの現行版（V1: `Assets/dennokoworks/CableGenerator`）で実装されている豊富な実用機能（2点選択配線、サーフェスなぞり描画、面スナップ投影、たわみ生成、細分化・均等配置、7種の断面プロファイル、制御点アタッチメント、EditorOnly ベイク出力など）を**すべて引き続き利用可能**にします。

その上で、V1 の課題であった **「Unity Splines パッケージへの依存」「2点選択時の一時コライダー付与の手間」「Inspector の深い階層を開かないと使えない操作導線」「均等分割による直線部の無駄なポリゴン消費」** を解消し、新たに **「ワンクリック LOD 生成」** と **「1本チェーンのボーン＆ウェイト自動生成」** を搭載します。

## 3. 機能要件詳細

### 3.1 配線作成・サーフェス配置（コライダー付与不要の即時レイキャスト）

V1 の [`EditorMeshRaycaster`](file:///c:/Users/dennoko/AppData/Local/VRChatCreatorCompanion/VRChatProjects/Unity_extension_development/Assets/dennokoworks/CableGenerator/Editor/Shared/EditorMeshRaycaster.cs)（BVH による `MeshFilter` 直接レイキャスト＋重心座標での頂点法線スムーズ補間）をすべての配置・投影処理の基盤とします。これにより、V1 で必要だった `CablePickingColliderManager`（一時 MeshCollider のバッチ付与・削除）を不要にし、**待ち時間ゼロ**でどんな背景メッシュにも配線できます。

| 機能 ID | 項目 | 詳細仕様 |
|---|---|---|
| **ROUT-01** | **2点クリック配線（Picking Mode）** | シーン上の任意のメッシュ表面を 2 回クリックするだけで、ヒット位置と面法線を取得して始点・終点を結ぶケーブルを即座に生成。1点目クリック後はマウス位置へのゴーストプレビューを表示。 |
| **ROUT-02** | **サーフェスなぞり描画（Surface Draw Mode）** | V1 の [`CableGeneratorInspector.SurfaceDraw.cs`](file:///c:/Users/dennoko/AppData/Local/VRChatCreatorCompanion/VRChatProjects/Unity_extension_development/Assets/dennokoworks/CableGenerator/Editor/Inspector/CableGeneratorInspector.SurfaceDraw.cs) を継承。メッシュ表面をドラッグでなぞると、3D Ramer–Douglas–Peucker（RDP）アルゴリズムで最適に間引かれた制御点列を生成し、面オフセット分だけ浮かせた状態で表面に這わせる。 |
| **ROUT-03** | **指定方向への面スナップ投影（Knot Projection）** | 選択中の制御点（単一または `Shift + クリック` による複数選択）を、指定方向（ワールド／ローカル、既定は下方向 `Vector3.down`）へレイキャストし、ヒットしたメッシュ表面（＋面オフセット）へ一括吸着・法線整列させる。 |

### 3.2 曲線・制御点（ノット）編集と補助ツール

V1 の `SplineContainer` カスタムエディタが持っていた操作性を、外部パッケージ（`com.unity.splines`）に頼らない軽量な独自データ構造で 100% 再現・強化します。

| 機能 ID | 項目 | 詳細仕様 |
|---|---|---|
| **KNOT-01** | **3つの接線モード（自動 / スムーズ / コーナー）** | ・**自動（AutoSmooth）**: Catmull-Rom / 自動接線により、点を置くだけで滑らかな曲線を維持（既定）。<br/>・**スムーズ（Mirrored）**: 前後の接線ハンドルが対称に連動。<br/>・**コーナー（Broken）**: 前後の接線ハンドルを独立制御（または長さ 0 で直角・鋭角折れ）。 |
| **KNOT-02** | **シーン上の直接追加（`⊕`）＆ 削除** | 各セグメント中間に表示される `⊕` ゴーストボタンを 1 クリック（またはドラッグ）するだけで、その区間の中点に新しい制御点を即座に挿入。削除も `[×]` または `Delete` キーで即実行。 |
| **KNOT-03** | **直観たわみ（Sag）操作（`▼` ハンドル ＆ スライダー）** | V1 の「たわみノット挿入＋降下距離スライダー」を継承しつつ、シーンビュー上の曲線中央に出る **`▼` たるみハンドルを上下にドラッグするだけ** で直観的にたわみ量を調整可能。さらに床・障害物メッシュがある場合は表面で自動停止（めり込み防止）するオプションを搭載。 |
| **KNOT-04** | **整列・細分化ユーティリティ** | V1 で好評の補助ボタンをすべて搭載：<br/>・**ループ（Closed）**: 始点と終点を繋いで輪にする。<br/>・**↕ 反転（Flip）**: 始点と終点の向きと接線を反転。<br/>・**⟺ 均等配置（Redistribute Evenly）**: 現在の曲線弧長に沿って全制御点を等間隔に再配置。<br/>・**始点-終点を N 等分**: 直線上に指定分割数で再配置。<br/>・**全区間を細分化（Subdivide）**: 各セグメントの弧長中点に制御点を一括挿入。 |
| **KNOT-05** | **ノット詳細調整（位置・回転・RateSlider）** | 選択ノットのワールド座標編集、15° ステップボタン付きの XYZ 回転（急カーブでのねじれ補正用）、および V1 の連続速度入力スライダー（Rate Slider）によるハンドル長調整を継承。 |

### 3.3 断面プロファイル & 曲率適応型メッシュ・LOD 生成

| 機能 ID | 項目 | 詳細仕様 |
|---|---|---|
| **MESH-01** | **V1 `CableProfile` & `ITwistedProfile` 完全互換** | V1 の [`CableProfile`](file:///c:/Users/dennoko/AppData/Local/VRChatCreatorCompanion/VRChatProjects/Unity_extension_development/Assets/dennokoworks/CableGenerator/Runtime/CableProfile.cs) と [`ITwistedProfile`](file:///c:/Users/dennoko/AppData/Local/VRChatCreatorCompanion/VRChatProjects/Unity_extension_development/Assets/dennokoworks/CableGenerator/Runtime/ITwistedProfile.cs)、および 7 種のプロファイル（`HeavyDuty`, `Flat`, `ParallelWire`, `Bundled`, `Clustered`, `SpiralTube`, `Twisted`）をそのまま利用。プロファイルの `Changed` イベントによるリアルタイムメッシュ更新も完全維持。 |
| **MESH-02** | **曲率適応型分割（Adaptive）＆ 均等分割のハイブリッド** | 直線区間は頂点を節約し、曲がっている箇所のみ自動で分割を密にする「曲率適応型分割（ポリゴン数 50〜80% 削減）」を標準搭載。V1 と同じ「均等分割（Resolution 指定）」にもトグル 1 つで切替可能（`SpiralTube` や `Twisted` ではねじれ周期に応じた最小分割数を自動確保）。 |
| **MESH-03** | **ねじれ防止フレーム（RMF + ノット回転合成）** | 3 次元の急カーブでも断面が裏返らない Double Reflection RMF（Rotation Minimizing Frames）を適用し、その上に各ノットの手動ロール回転と `ITwistedProfile` の距離比例ツイストを合成。 |
| **MESH-04** | **V1 継承の UV0 タイリング & UV1 棚パッキング** | 累積弧長に応じた UV0 の V タイリング（`uvTiling`）と、複数ループを持つ複合プロファイルでもライトマップ UV が重ならない V1 の棚パッキング（`CalculateUV1Layout`）を完全継承。 |
| **MESH-05** | **【V2新規】ワンクリック自動 LOD 生成（`LODGroup`）** | **`[⚡LOD]` トグルを ON にするだけ** で、曲線の分割密度とプロファイル頂点の間引き率を段階的に変えた **LOD0（100%）/ LOD1（中距離）/ LOD2（遠距離）** メッシュを自動生成し、`LODGroup` コンポーネントを自動構築。 |

### 3.5 【V2新規】1本チェーンのボーン＆ウェイト自動生成（PhysBone 等への素体提供）

外部 SDK（VRChat SDK 等）への依存を持たず、VRC アバターやワールドの PhysBone でそのまま揺らせる `SkinnedMeshRenderer` をワンクリックで生成します。

| 機能 ID | 項目 | 詳細仕様 |
|---|---|---|
| **BONE-01** | **1本チェーンのボーン＆解析的ウェイト自動生成** | **`[🦴ボーン]` トグルを ON にするだけ** で、始点から終点へ向かう素直な 1 本のボーン階層（`Bone_0` → `Bone_1` → ...）を生成し、`SkinnedMeshRenderer` に自動変換。曲線上の弧長から数学的に滑らかな Hermite 補間ウェイトを直接算出するため、複合プロファイル（束線やスパイラル等）でもウェイト破綻がゼロ。 |
| **BONE-02** | **ボーン本数指定 ＆ LOD・アタッチメント連動** | ボーン数（4〜32本、既定 8 本）をスライダーで指定可能。LOD 有効時は全 LOD メッシュを同一ボーン階層へバインドし、制御点アタッチメントも最寄りボーンの子へ自動配置して一緒に揺らせる。 |

|---|---|---|

## 4. UI / UX 設計（説明書不要の Scene 直観操作 ＋ 馴染み深い V1 Inspector）

**「普段の 9 割の作業は Scene ビュー上のカプセルバーと直接ギズモだけで 3 秒で終わり、細かい数値調整や一括投影をしたい時は V1 と同じダークテーマの Inspector カード UI でじっくり触れる」** ハイブリッド構成にします。

### 4.1 シーンビュー・カプセルオーバーレイ（よく使う操作を 1 列に集約）
Inspector の折りたたみを開閉しなくても、Scene ビュー上部のコンパクトなバーから V1 の主要モードと V2 の新機能をワンクリックで呼び出せます。

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│ [🎯2点配線] [✏️なぞり描画] │ Profile:[HeavyDuty▼] │ [▼たわみ] [🧲面投影] │ [⚡LOD] [🦴ボーン] │ [💾メッシュ保存] │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **`[🎯 2点配線]`**: V1 の「2点選択でSplineを設定」を即起動（コライダー付与不要でどのメッシュでも即クリック可能）。
- **`[✏️ なぞり描画]`**: V1 の「サーフェスに描いて配線」を即起動。
- **`Profile [▼]`**: 割り当て中の `CableProfile` を切替（未設定時はデフォルトプロファイルを自動セットし、「プロファイル未設定でメッシュが出ない」初心者のつまずきを解消！）。
- **`[▼ たわみ]`**: クリックでたわみノット挿入＆Scene 上の `▼` ハンドルで直観ドロップ調整。
- **`[🧲 面投影]`**: 選択中のノットを下方向（または設定方向）のメッシュ面へワンクリックでスナップ投影。
- **`[⚡ LOD]` / `[🦴 ボーン]`**: 軽量化 LOD と揺れもの用ボーンの ON/OFF トグル。
- **`[💾 メッシュ保存]`**: V1 と同じ `.asset` 保存＆ `<name>_cable_baked` 生成をワンクリック実行。

### 4.2 シーンビュー直接操作ギズモ（On-Scene Direct Gizmos）
V1 の色付きノット球・インデックスラベル（`[0]▶`, `◀[N]`）・接線ハンドルに加え、以下の直観ギズモを表示します。

- **中間ゴースト点（`⊕`）**: 各セグメントの中間に小さく表示。クリックまたはドラッグするだけでその場に新しいノットを挿入（Inspector の「＋制御点を追加」を押しに行く手間を削減）。
- **たわみハンドル（`▼`）**: 曲線の最下点に表示。上下ドラッグでたわみ距離を直接調整。
- **ノット選択時のクイックバー**: 選択したノットのすぐ近くに `[自動 / スムーズ / コーナー]` 切替・`[🔌アタッチ追加]`・`[×削除]` のミニボタンを表示し、視線を動かさずに編集可能。

### 4.3 Inspector UI（V1 `CableGeneratorTheme` 準拠）
V1 の `dennoko.dev` カラースキーマ（`CableGeneratorTheme`）と折りたたみカード構造をそのまま維持・統合します（V1 で `SplineContainer` 側に分かれていた「ステータスバー（全長・ループ・↕反転・⟺均等配置）」「制御点リスト」「ノット詳細パネル」も、`CableGenerator` 本体 Inspector 内に綺麗に統合されるため、コンポーネント間を行き来する必要がなくなります）。

### 5.2 `CableSpline` & `CableKnot` データ構造（`UnityEngine.Splines` の軽量代替）

V1 のコードが前提としていた `Spline` / `BezierKnot` / `TangentMode` の API とイベント（`KnotInserted`, `KnotRemoved`, `Changed`）を、外部パッケージ無しの標準 C#（`Vector3`, `Quaternion`）でそのまま置き換えます。

```csharp
public enum CableTangentMode
{
    AutoSmooth = 0,  // 自動（Catmull-Rom 接線自動算出）
    Mirrored   = 1,  // スムーズ（入出接線が対称）
    Broken     = 2,  // コーナー（入出接線が独立 / 角出し）
}

[Serializable]
public struct CableKnot
{
    public Vector3 position;          // ローカル座標
    public Vector3 tangentIn;         // ローカル空間（knot.rotation 基準）の入力接線
    public Vector3 tangentOut;        // ローカル空間（knot.rotation 基準）の出力接線
    public Quaternion rotation;       // ノットの向き（法線整列・手動ツイスト補正用）
    public CableTangentMode mode;     // 自動 / スムーズ / コーナー
}
```
- これにより、V1 で作り込まれた **「2点選択」「サーフェス描画」「たわみノット挿入・更新」「面スナップ投影」「ノット細分化・等分・均等配置・反転」「`CableKnotAttachment` のインデックス自動シフト」** のすべてのロジックが、挙動を損なうことなく `com.unity.splines` ゼロ依存で動作します。
- さらに V1 では `SplineContainer` と `CableGenerator` の 2 つのコンポーネントに分かれていた Inspector が **`CableGenerator` 1 つに統合** され、使い勝手が大幅に向上します。
