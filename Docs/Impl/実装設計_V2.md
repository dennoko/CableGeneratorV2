## 3. コアクラス設計（Runtime）

### 3.1 `CableProfile` & `ITwistedProfile`（V1 互換）
- `CableProfile : ScriptableObject`
  - `abstract Vector2[] GetVertices()`
  - `abstract Vector2[] GetNormals()`
  - `abstract float[] GetUCoords()`
  - `virtual int GetVerticesPerLoop()`
  - `virtual float[] GetPerimeters()`
  - `virtual float GetMaxRadius()` — 断面頂点の原点からの最大距離（コライダー接地オフセット用）
- 組み込みプロファイル（7種）：
  - `HeavyDutyCableProfile`, `FlatCableProfile`, `ParallelWireProfile`, `BundledCableProfile`, `ClusteredCableProfile`, `SpiralTubeProfile`, `TwistedCableProfile`

### 3.2 `CableSpline` & `CableKnot`（Splines パッケージ代替）
- `CableTangentMode`：`AutoSmooth`, `Mirrored`, `Continuous`, `Broken`
- `CableKnot` 構造体：
  - `Vector3 position`（ローカル座標）
  - `Vector3 tangentIn`, `Vector3 tangentOut`（ノット回転空間内の相対接線ベクトル）
  - `Quaternion rotation`（ノットの姿勢）
  - `CableTangentMode mode`
  - `float sag`（このノットから次のノットへ向かう区間の直接たわみ量 [m]。2点のみのケーブルでも中間ノットを増やさずに `▼` ハンドルでたわませることが可能）
- `CableSpline` クラス：
  - `List<CableKnot> knots`, `bool closed`
  - `event Action<CableSpline, int, CableSplineModification> Changed`
  - **自動接線算出（Catmull-Rom 補間）**: `mode == AutoSmooth` のノットでは、前後のノット位置 $\mathbf{P}_{i-1}, \mathbf{P}_{i+1}$ から滑らかな 3 次ベジェ制御点を自動算出する。
  - **区間たるみ合成**: 区間 $i$ に `sag > 0` が設定されている場合、3次ベジェ評価点に対して放物線重力オフセット $\Delta \mathbf{y}(u) = -4 u(1-u) \cdot \text{sag} \cdot \mathbf{g}_{\text{local}}$（$u \in [0,1]$）および接線微分を解析的に加算する。

### 3.3 `CableCurveSampler`（曲率適応型サンプリング ＆ RMF ＆ 床接地）
- `SamplePoint` 構造体：
  - `Vector3 localPos`, `Vector3 localTangent`, `Vector3 localRight`, `Vector3 localUp`
  - `float distance`（始点からの累積ワールド弧長）
  - `float normalizedT`（全長に対する正規化弧長 $0 \sim 1$）
- **サンプリングモード**:
  1. **曲率適応型（Adaptive）**: 各ベジェ区間を初期分割した後、隣接サンプル間の接線角度差 $\Delta \theta$ が `maxAngleError`（例: $5^\circ$）を超える区間を再帰的に二分割。直線区間は最小分割となり頂点数を 50〜80% 削減。`ITwistedProfile` 使用時はねじれが潰れないよう最小ステップ長を保証。
  2. **均等分割（Uniform）**: V1 互換の `resolution` 等分割。
- **Double Reflection RMF（Rotation Minimizing Frames）**:
  - 初期フレーム $(\mathbf{T}_0, \mathbf{R}_0, \mathbf{U}_0)$ から順次に二重反射法でねじれ最小フレームを伝播し、急カーブでの法線反転（フリップ）を防止。
- **リアルタイム床・障害物接地（Surface Collision Draping）**:
  - `enableSurfaceCollision` が ON の場合、たるみ区間内の各サンプル点について上方から下方向へ `Physics.Raycast` を実行し、コライダー表面＋プロファイル半径（`GetMaxRadius() + surfaceOffset`）より下に潜り込んでいる点を表面上にクランプ＆前後平滑化する。

### 3.4 `CableGenerator`（メッシュ生成・UV1 棚パッキング・LOD・ボーン統合）
- **メッシュ押出 & UV1 棚パッキング**:
  - V1 のループ境界スキップおよび `CalculateUV1Layout`（Shelf Packing）を完全継承。
  - 断面スケール倍率 `radiusScale`（既定 `1.0`）により、プロファイルアセットを書き換えずに太さを微調整可能。
- **手続き型 LOD 自動生成（`CableLodBuilder`）**:
  - `enableLod` が ON のとき、子階層に `Cable_LOD0`, `Cable_LOD1`, `Cable_LOD2` を自動管理し、`LODGroup` を構成：
    - `LOD0`（画面占有率 100%〜25%）: 断面頂点間引きなし（Step=1）、角度許容値 $\times 1.0$
    - `LOD1`（画面占有率 25%〜8%）: 断面ループ頂点を約 1/2 に間引き、角度許容値 $\times 2.2$
    - `LOD2`（画面占有率 8%〜2%）: 断面ループ頂点を最小（3〜4角）に間引き、角度許容値 $\times 4.5$
- **1本チェーンのボーン＆解析的ウェイト自動生成（`CableRigBuilder`）**:
  - `enableBones` が ON のとき、子階層 `Bones_Root` 以下に `Bone_0` → `Bone_1` → ... → `Bone_{K-1}`（$K = \text{boneCount}$）を生成し、曲線上の等弧長位置・接線方向へ配置。
  - 各リングの正規化弧長 $s \in [0, 1]$ に対し、連続ボーン座標 $b = s \cdot (K - 1)$ から主ボーン $i = \lfloor b \rfloor$、次ボーン $j = \min(i + 1, K - 1)$、補間率 $f = b - i$ を求め、SmoothStep $w_1 = f^2(3 - 2f), w_0 = 1 - w_1$ によって滑らかな `BoneWeight` を 0 ミリ秒台で算出。

## 4. エディタ UI・ツール設計（Editor）

### 4.1 `EditorMeshRaycaster` の全面活用（コライダー付与不要化）
- V1 の BVH メッシュレイキャスターを拡張し、「サーフェスなぞり描画」だけでなく **「2点選択配線」** および **「指定方向への面スナップ投影」** でも標準使用する（`MeshFilter` が無いオブジェクトに対しても `Physics.Raycast` をフォールバック併用）。

### 4.2 Scene ビュー直接ギズモ ＆ カプセルオーバーレイ
- **Scene 上の直接操作ギズモ**:
  - 各ノット球（`●`）のドラッグ移動、クリック選択（Shift 複数選択）、選択ノット直上の `[自動 / スムーズ / コーナー]`・`[＋アタッチ]`・`[×削除]` ミニバー表示。
  - 各セグメント中点の **`⊕` 追加ボタン**: 1 クリックでその位置にノットを挿入。
  - 各セグメント中点の **`▼` たわみハンドル**: 上下ドラッグでその区間の `sag` 値を直接増減。
- **Scene ビュー上部のクイックツールバー**:
  - 編集中オブジェクト選択時、Scene ビュー上部にコンパクトなカプセルバーを描画し、`[2点配線]` `[なぞり描画]` `[たわみ]` `[面投影]` `[LOD]` `[ボーン]` `[保存]` にワンクリックでアクセス可能にする。
