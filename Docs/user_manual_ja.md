# CableGenerator V2 ユーザーマニュアル

CableGenerator V2 は、Unity 上で直観的かつ最少手数でケーブル・配線メッシュを生成できるエディタ拡張ツールです。  
Unity 公式の Splines パッケージに依存せず完全スタンドアロンで動作し、コライダーの事前準備なしで背景メッシュに即座に配線できます。

## 1. クイックスタート

### 1.1 ツールウィンドウの開き方

以下のいずれかの方法で専用のツールウィンドウを開きます。

- メニューバー: **`Tools` > `dennokoworks` > `Cable Generator`**
- Hierarchy ウィンドウの右クリック: **`Cable Generator V2` > `Open in Window`**
- `CableGenerator` コンポーネントの Inspector: **「Cable Generator を開く」** ボタン

### 1.2 ケーブルの新規作成

1. ツールウィンドウ上部の **「＋ 新規」** ボタンをクリックします。  
   （または Hierarchy 右クリック > **`Cable Generator V2` > `Create Cable`**）
2. シーン内に新しいケーブルオブジェクトが生成され、自動的に編集対象になります。

### 1.3 最速配線手順（2点間に配線 / 描いた線に配線）

シーン内のオブジェクトにコライダーが付いていなくても、メッシュ表面へ直接レイキャストして配線できます。

#### A. 2点間に配線（端点を指定して直線・たわみ配線）
1. ウィンドウの **「配線」** タブにある **「2点間に配線」** ボタンをクリックします（またはシーン上部ツールバーのアイコンをクリック）。
2. シーンビュー上で始点にしたいメッシュ表面をクリックします。
3. 続けて終点にしたいメッシュ表面をクリックします。
4. 2点間を結ぶケーブルが即座に生成されます。`Esc` キーまたはバナーの「終了」でモードを終了します。

#### B. 描いた線に配線（フリーハンドで表面に配線）
1. ウィンドウの **「配線」** タブにある **「描いた線に配線」** ボタンをクリックします。
2. シーンビュー上でメッシュの表面をドラッグします。
3. マウスを離すと、なぞった軌跡に沿って制御点が自動生成され、表面からわずかに浮いた位置にケーブルが配線されます。

### 1.4 たるみ（Sag）の調整

1. ケーブルを選択すると、シーンビュー上の各区間の中央に **`▼`（たるみハンドル）** が表示されます。
2. この `▼` ハンドルを下方向にドラッグするだけで、直観的にたるみをつけることができます。
3. ウィンドウの **「制御点」** タブにある「たるみ」スライダーを動かすと、全区間に一括でたるみを適用できます。

### 1.5 断面プロファイルの選択

1. ウィンドウの **「ケーブルタイプ」** タブを開きます。
2. 7 種類の組み込みプロファイル（太線・平線・並列線・束線・集合線・らせん管・撚り線）のサムネイルから、使用したい形状をクリックして選択します。
3. シーン上のケーブルメッシュがリアルタイムに選択した断面へ切り替わります。

### 1.6 出力（メッシュ / FBX / Prefab）

1. ウィンドウ右下の **「出力」** ボタン（または「出力」タブ）を使用します。
2. **メッシュ (.asset)**: メッシュアセットとしてプロジェクトに保存し、ベイク済みオブジェクトをシーンに配置します。
3. **FBX**: 現在の形状で固定した `.fbx` ファイルとしてエクスポートします（ボーン付きでの書き出しにも対応）。
4. **Prefab (LOD)**: LOD0〜LOD2 のメッシュと `LODGroup` を設定済みの `.prefab` として保存します。
5. 出力時、元のケーブルオブジェクトは非アクティブ化されて保持されるため、いつでも再編集が可能です。

## 2. 機能一覧

### 2.1 UI 構成

CableGenerator V2 の操作は、主に **ツールウィンドウ** と **シーンビュー** の 2 か所で行います。Inspector は要約を見るためのもので、操作には使いません。

**ツールウィンドウ（Cable Generator）**
設定と出力を行う場所です。上から順に次のものが並びます。

- **トップバー**: バージョンの確認、言語の切り替え（JA / EN）、設定メニュー。
- **対象カード**: 編集するケーブルの選択、固定（ピン留め）、新規作成。
- **タブ**: 「配線」「制御点」「ケーブルタイプ」「出力」の 4 つ。作業の順に並んでいますが、どこからでも使えます。
- **作業中バナー**: 配線の作業中だけ表示され、次にする操作と終了の方法を示します。
- **タブの中身**: 選んだタブの設定です。ここだけがスクロールします。
- **出力ドックとフッター**: 出力先フォルダ、出力形式の要約、ケーブルの情報（制御点数・全長・ポリゴン数）と「出力」ボタン。

**シーンビュー**
ケーブルの形を直接整える場所です。ケーブルを選ぶと、シーンの上部に S1 ツールバーが出て、配線の開始・接線モードの切り替え・LOD などをワンクリックで操作できます。シーン上では、制御点の移動や回転、区間の中央にある ⊕ での制御点の追加、▼ のドラッグによるたるみの調整ができます。操作中はカーソルの近くにヒントが、操作のあとには結果が短く表示されます。

**Inspector**
ケーブルの要約（制御点数・全長など）と、ツールウィンドウを開くボタンだけを表示します。

## 3. 機能詳細

### 3.1 配線（Wire タブ）

#### 配線方式（Method）
- **2点間に配線 (`tile-pick`)**:
  - メッシュの表面を 2 回クリックするだけで、法線に応じた自然な立ち上がりを持つケーブルを生成します。
  - **詳細設定**: `接線ハンドルの長さ` で端点の立ち上がり曲率を調整できます。
- **描いた線に配線 (`tile-draw`)**:
  - 表面上をドラッグして描いた軌跡から、3D RDP（Ramer–Douglas–Peucker）アルゴリズムにより適切な数の制御点を自動抽出します。
  - **詳細設定**:
    - `表面オフセット (m)`: 表面から浮かせる距離（初期値: 0.003m = 3mm）。
    - `簡略化`: 点の間引き許容誤差。値を大きくすると制御点数が減少します。
    - `サンプル間隔 (px)`: マウスドラッグ時のサンプリング密度。
    - `生成時の点種別`: 生成される制御点の接線モード（自動 / 滑らか）。
- **裏面を無視**（2 つの配線方式に共通の詳細設定。初期値: ON）: 面を裏側から見たときは当たらないようにします。壁や床の向こう側にある面を拾わなくなります。OFF にすると、詳細を閉じているときに `裏面も判定` のチップが出ます。

#### 制御点操作（Knots）
- **リスト表示**: 全制御点のインデックスと座標を一覧表示。項目クリックでシーンカメラがその制御点にフォーカスします。
- **アイコンボタン**:
  - `＋`: 選択中の制御点の後ろ（未選択時は末尾）に制御点を追加。
  - `⇄（反転）`: 始点と終点を入れ替え、曲線の向きを反転。
  - `⟺（等間隔）`: 曲線全体の長さを保ったまま、制御点を等間隔に再配置。
- **ループ接続**: 有効にすると終点と始点が滑らかに接続され、閉じたループになります。
- **分割・追加（詳細内）**:
  - `始点〜終点の等分割`: 始点と終点の直線区間を指定した分割数で再配置します。
  - `全区間の細分化`: すべてのセグメントの中間点に制御点を一括挿入します。
  - `追加時の点種別`: 分割時に挿入される制御点のモード（自動 / 滑らか / 角）。

#### 面への吸着（Snap to Surface）
- 選択中の制御点を、指定した方向の最も近いメッシュ表面へ一括投影します。
- **方向**: `下`（Vector3.down）/ `上`（Vector3.up）/ `指定`（任意の Vector3 入力）。
- **ケーブルのローカル方向**: 有効にすると、指定方向をケーブルの Transform 向きに合わせて回転させます。
- **最大距離 (m)**: この距離内に表面が検出されない制御点は移動させずに保持します。
- **判定対象レイヤー**: クリック・描画・投影の対象とする LayerMask を設定します（コライダーは不要です）。
- **裏面を無視**（詳細内。初期値: ON）: 投影する方向から見て裏向きの面には吸着しません。

### 3.2 制御点の調整（制御点タブ）

#### 選択中の制御点（Selected Knot）
シーンビューで制御点をクリック（またはドラッグによる矩形選択）すると、該当する制御点のパラメータが表示されます。

- **位置 / 座標系**: ワールド座標系またはローカル座標系での位置編集。
- **接線モード**:
  - **自動 (`Auto`)**: 前後の制御点から滑らかな曲線を自動計算します（推奨）。
  - **滑らか (`Smooth`)**: イン側とアウト側の接線が直線上に並び、方向が対称に連動します。
  - **角 (`Corner`)**: イン側とアウト側の接線方向・長さを個別に独立調整できます（直角・鋭角の折り曲げに対応）。
- **接線の長さ**: イン側 / アウト側の接線ハンドル長さを個別に微調整。
- **回転（ねじれ補正）**: 急カーブ等でケーブルの断面がねじれた場合、軸周りに回転を与えて補正します。`リセット` ボタンで 0 に戻せます。

#### アタッチメント（Attachments）
選択中の制御点に、コネクタや結束バンドなどのモデルを追従させます。制御点を移動・回転させると自動で追従します。設定はすべてこのカードで行え、Inspector を開く必要はありません。

- **＋ アタッチ**: 選択中の制御点にアタッチメントを追加します（制御点を 1 つ選んでいるときだけ）。シーンの S1 ツールバーの `アタッチ` からも追加でき、そのときはこのタブが開きます。
- 制御点を選んでいないときは、ケーブルに付いているアタッチメントが一覧表示され、クリックするとその制御点を選びます。
- 各アタッチメントの設定項目:
  - **制御点番号**: アタッチ先の制御点。変えるとその点へ付け替えます。
  - **Prefab / FBX**: 配置するモデル。
  - **位置オフセット / 回転オフセット / スケール**: 制御点の位置・向きからのずれ。
  - **アタッチメントを更新**: モデルが消えていれば作り直し、制御点の位置と向きに合わせ直します。
  - **ゴミ箱アイコン**: アタッチメントを外します。
- 出力（メッシュ / FBX / Prefab）には、アタッチメントのモデルも含まれます。

#### たるみ（Sag）
- **全体 (m)**: スライダーを動かすと、すべての区間に同一のたるみ量を一括で適用できます。
- **区間別詳細設定**:
  - 各区間ごとのたるみ量（垂下量）を個別に確認・調整できます。
  - **対称ハンドル / 接線ハンドルの長さ**: たるみハンドルの接線形状を微調整します。
  - **たわみ制御点を挿入（V1 互換）**: 曲線計算ではなく、各区間の中央に実際の制御点を追加して下げる方式に変換します。

#### オブジェクト表面に沿わせる（Surface Collision）
- トグルを有効にすると、たるみによって下がったケーブルが床や壁のメッシュ表面に当たった際、メッシュを突き抜けずに表面に接地・追従します。
- **接地対象レイヤー**: 接地判定を行う LayerMask を指定します。

### 3.3 断面プロファイル（ケーブルタイプタブ）

#### 断面プレビュー
タブの先頭に、選択中のプロファイルの断面を大きく表示します。値を変えるとその場で描き直されます。下の行には頂点数・直径・プロファイルの種類が表示されます。

#### 断面プロファイル（Profiles）
7 種類のプロファイルアセットが標準付属しています（`Profile_sample` フォルダ）。新しく作ったケーブルは **太線 (Heavy)** から始まります。

1. **太線 (Heavy)**: 直径の大きな単線高圧ケーブル・ホース。
2. **平線 (Flat)**: リボンケーブル・フレキシブルフラットケーブル。
3. **並列線 (Parallel)**: 複数本の芯線が水平に並んだ給電線。
4. **束線 (Bundled)**: 中心線の周囲に複数の細線が束ねられたケーブル束。
5. **集合線 (Clustered)**: 複数本の独立した電線がランダムに束ねられた集合配線。
6. **らせん管 (Spiral)**: 保護用スパイラルチューブ・蛇腹ホース。
7. **撚り線 (Twisted)**: 複数本の線がらせん状にねじれ合わされたツイストペア線。

- **複製して編集**: 現在のプロファイルを複製してこのケーブル専用のアセットを作成します。他のケーブルに影響を与えることなく独自の調整が可能です。
- **新規**: 任意のプロファイル種別を選んでデフォルト設定のアセットを新規作成します。

#### 太さ・分割数（Mesh Settings）
- **太さ (`radiusScale`)**: 断面全体の太さ倍率（スライダー操作）。
- **分割方式**:
  - **自動 (`Auto`)**: 曲率適応型分割。直線部分はポリゴンを節約し、カーブがきつい箇所のみ適応的に分割数を増やします。
  - **均等 (`Even`)**: 全長にわたって一定の細かさで均等分割します。
- **許容角 (°) / 分割数 (`resolution`)**: 曲率適応の閾値、または断面方向・長さ方向の分割密度を調整します。
- **UV タイリング**: ケーブルの長さに応じたテクスチャの繰り返し回数を調整します。

### 3.4 出力・LOD・ボーン（Output タブ）

#### 軽量化（LOD）
- **LOD トグル**: 有効にすると、Unity 標準の `LODGroup` コンポーネントと連動する 3 段階のメッシュを自動生成します。
  - **LOD0**: フル品質メッシュ（100%）。
  - **LOD1**: 中距離用（断面分割および長さ方向の分割を約 50% に削減）。
  - **LOD2**: 遠景用（約 30% の最軽量メッシュ）。
  - **非表示 (Cull)**: 指定した画面占有率を下回ると描画を停止（カリング）します。

#### 形式・エクスポート
- **メッシュ (.asset)**:
  - ケーブルメッシュを `.asset` ファイルとして保存し、シーン内にメッシュを貼り付けた GameObject を配置します。
- **FBX**:
  - 現在の形状をベイクした汎用 `.fbx` モデルとしてプロジェクトに出力します。
  - **書き出す LOD**: 単一の LOD（LOD0 / LOD1 / LOD2）を選んで出力できます。
  - **ボーンを付与**:
    - 有効にすると、始点から終点へ向かう 1 本チェーンのボーン（`Bone_0` 〜 `Bone_N`）とスキンウェイトを自動生成した SkinnedMesh として出力します。
    - **ボーン数**: 生成するボーンの数を指定します。
    - VRChat の PhysBone コンポーネントは、ルートボーンである `Bone_0` にアタッチして設定してください。
  - **シーンに配置する**: 有効時、書き出した FBX をシーン上に自動配置します。
- **Prefab (LOD)**:
  - LOD0（フル）・LOD1（約 50%）・LOD2（約 30%）の 3 段階のメッシュと、それを切り替える `LODGroup` を設定した `.prefab` を保存します。
  - 「軽量化（LOD）」が OFF でも LOD 付きで保存します。切り替えの画面占有率は「軽量化（LOD）」の中間・遠景・非表示の値を使います。
  - メッシュは Prefab と同じフォルダの `〜_LODs.asset` に 3 つまとめて保存されます。Prefab を別のフォルダへ移すときは、このアセットも一緒に移してください。
  - アタッチしたモデル（コネクタなど）も Prefab の中に含まれます。
  - **シーンに配置する**: 有効時、保存した Prefab のインスタンスを元のケーブルの位置に配置します。

#### 出力しなくてもアップロードできます
生成されたメッシュ（LOD 有効時は LOD1・LOD2 と `LODGroup` も含む）はシーンにそのまま保存されるため、出力（ベイク）を行わなくても VRChat ワールドにアップロードできます。アップロード後に形を直したいときは、シーン上のケーブルをそのまま編集してください。

- ケーブルの本数・頂点数に応じてシーンファイル（`.unity`）のサイズが増えます。気になる場合は下記の出力でメッシュを外部ファイル化してください。
- プロファイルアセットの変更などで形が変わるケーブルがあると、シーンを開いたときに「未保存」になることがあります。保存してからアップロードしてください。
- `CableGenerator` コンポーネントを外しても、その時点のメッシュはオブジェクトに残ります。

#### 非破壊ベイク設計
出力完了後、元の `CableGenerator` オブジェクトは非アクティブ化され、`EditorOnly` タグが付与されてシーン内に保持されます。  
形状を修正したくなった場合は、出力されたオブジェクトを削除し、元のオブジェクトを再度アクティブ化するだけで、いつでも編集を再開できます。

### 3.5 シーンビュー操作（S1 ツールバーと直接編集）

ケーブル選択中、シーンビュー上に専用の操作ツールバーが表示されます。

#### S1 ツールバーアイコン
- **配線グループ**: `2点間に配線` / `描いた線に配線` の開始・終了トグル。
- **選択点グループ**:
  - 接線モード（`自動` / `滑らか` / `角`）の切替。
  - `面へ投影`: 選択中の制御点を直下の面へ吸着。
  - `アタッチ`: 選択中の制御点にアタッチメントを追加し、ウィンドウの「制御点」タブを開きます（モデルや位置の調整はそこで行います）。
  - `削除`: 選択中の制御点を削除（最低2点は保持されます）。
- **ケーブル全体トグル**:
  - `表面接地判定`: 床・物への接地ストップの ON/OFF。
  - `LOD`: LOD 自動生成の ON/OFF。
- **ウィンドウを開く**: Cable Generator ウィンドウを即座に開いて前面に表示。

#### シーン上の直接編集
- **制御点の選択**:
  - 制御点（球）をクリックで単一選択。
  - `Shift` または `Ctrl` を押しながらクリックで複数追加選択。
  - シーン上の空き領域からドラッグして矩形選択。
- **移動マニピュレータ**: 移動矢印ハンドルをドラッグして位置を移動。
- **区間追加ボタン（`⊕`）**: 各セグメントの中央に表示される `⊕` アイコンをクリックすると、その位置に制御点が即座に挿入されます。
- **たるみハンドル（`▼`）**: 区間の中央に表示される `▼` アイコンを下方向へドラッグすると、その区間のたるみ量を直観的に増減できます。
